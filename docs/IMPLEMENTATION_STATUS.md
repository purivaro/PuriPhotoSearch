# สถานะการพัฒนา

ณ 18 พ.ย. 2569 (ชุดงานที่สอง: เพิ่มการวิเคราะห์ใบหน้าอัตโนมัติและหน้าตรวจสอบใบหน้า ต่อจาก Phase 0 + เส้นทางหลักของ Phase 1) หลักฐานการทดสอบอยู่ใน [TEST_REPORT.md](TEST_REPORT.md)

ป้ายที่ใช้:

- **ทำแล้ว ทดสอบแล้ว** — มีในโค้ด และมีเทสต์หรือการรันจริงที่ผ่านยืนยัน
- **ทำแล้ว ยังไม่ได้ทดสอบ** — มีในโค้ด แต่ยังไม่มีเทสต์อัตโนมัติยืนยัน (อาจเคยเปิดดูด้วยตา)
- **บางส่วน** — ใช้ได้บางกรณี ระบุสิ่งที่ขาด
- **ยังไม่ทำ** — ไม่มีในโค้ด และไม่มีปุ่มลวงใน UI
- **ติดข้อจำกัด** — ทำต่อไม่ได้จนกว่าจะมีคำตอบ/ข้อมูล

## เส้นทางหลัก

เลือกโฟลเดอร์ → ตรวจรายการ → เพิ่มกิจกรรม → แสดงรูป → ตั้งชื่อบุคคล → ค้นหารูป → เปิดต้นฉบับ → ส่งออกสำเนา

**ทำแล้ว ทดสอบแล้ว** ในหน้าต่างแอปจริงด้วย `e2e/run.sh` ทั้งแบบ `pnpm tauri dev` และแบบ `.app` ที่ bundle แล้ว (debug)
e2e นี้ตั้งชื่อบุคคลด้วยการลากกรอบใบหน้าเอง (ปิดตัววิเคราะห์ใบหน้าเพื่อให้ผลแน่นอน)

การวิเคราะห์ใบหน้าอัตโนมัติ (ดาวน์โหลดโมเดลปุ่มเดียว → ตรวจใบหน้าตอนเพิ่มรูป → ข้อเสนอชื่อ → หน้าตรวจสอบ): **ทำแล้ว ทดสอบแล้วที่ชั้น Rust**
และกดผ่าน UI จริงกับโมเดลจริง รูปจริง 292 รูป และรายชื่อจริงจากรุ่น Python ผ่าน dev bridge (ดาวน์โหลดโมเดลผ่านเครือข่าย, นำรายชื่อเข้า,
ใช่/ไม่ใช่/ตั้งชื่อ/ไม่ใช่ใบหน้า, ข้อเสนอในตัวดูภาพ) — **ยังไม่อยู่ใน e2e อัตโนมัติ** (e2e ปิดตัววิเคราะห์ใบหน้า)
