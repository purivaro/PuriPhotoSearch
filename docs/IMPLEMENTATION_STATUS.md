# สถานะการพัฒนา

ณ 18 พ.ย. 2569 (ชุดงานแรก: Phase 0 + เส้นทางหลักของ Phase 1) หลักฐานการทดสอบอยู่ใน [TEST_REPORT.md](TEST_REPORT.md)

ป้ายที่ใช้:

- **ทำแล้ว ทดสอบแล้ว** — มีในโค้ด และมีเทสต์หรือการรันจริงที่ผ่านยืนยัน
- **ทำแล้ว ยังไม่ได้ทดสอบ** — มีในโค้ด แต่ยังไม่มีเทสต์อัตโนมัติยืนยัน (อาจเคยเปิดดูด้วยตา)
- **บางส่วน** — ใช้ได้บางกรณี ระบุสิ่งที่ขาด
- **ยังไม่ทำ** — ไม่มีในโค้ด และไม่มีปุ่มลวงใน UI
- **ติดข้อจำกัด** — ทำต่อไม่ได้จนกว่าจะมีคำตอบ/ข้อมูล

## เส้นทางหลัก

เลือกโฟลเดอร์ → ตรวจรายการ → เพิ่มกิจกรรม → แสดงรูป → ตั้งชื่อบุคคล → ค้นหารูป → เปิดต้นฉบับ → ส่งออกสำเนา

**ทำแล้ว ทดสอบแล้ว** ในหน้าต่างแอปจริงด้วย `e2e/run.sh` ทั้งแบบ `pnpm tauri dev` และแบบ `.app` ที่ bundle แล้ว (debug)
การตั้งชื่อบุคคลในรุ่นนี้ทำด้วยการลากกรอบใบหน้าเอง เพราะยังไม่มีการวิเคราะห์ใบหน้าอัตโนมัติ

## ขั้นต่อไปที่ทำได้โดยไม่ต้องรอคำตอบ

1. ต่อการตรวจใบหน้าเข้า pipeline ของแอป (ผลทดลองผ่านแล้ว): กรอบใบหน้าอัตโนมัติในตัวดูภาพ → จัดกลุ่ม → หน้าตรวจสอบ (S16) โดยให้ผู้ใช้ชี้ไฟล์โมเดลเอง

3. ตัวนำเข้ารายชื่อ กลุ่ม และใบหน้าตัวอย่างจากฐานเดิม
4. relink + archive + หน้าแหล่งรูป (S14) — จำเป็นก่อนย้ายรูปจากฐานเดิม เพราะ 84% ไม่อยู่ที่เดิม
