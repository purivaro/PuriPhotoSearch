• ส่งออกสำเนาพร้อมลายน้ำได้ — เปิด “ใส่ลายน้ำ” ในหน้าต่างส่งออก เพิ่มโลโก้ (PNG พื้นใสดีที่สุด) แล้วเลือกตำแหน่ง ขนาด และความทึบ ดูตัวอย่างบนรูปที่เลือกได้ทันที
• ใช้ร่วมกับการย่อขนาดได้ ลายน้ำมีสัดส่วนเท่ากันทุกขนาดสำเนา · แอปเก็บโลโก้ไว้ใช้ซ้ำ และไฟล์ต้นฉบับไม่ถูกแตะ
• รุ่นนี้ปรับโครงสร้างคลัง แอปสำรองคลังเดิมไว้ให้ก่อนเมื่อเปิดครั้งแรก หลังจากนั้นแอปรุ่นก่อนหน้าจะเปิดคลังนี้ไม่ได้
