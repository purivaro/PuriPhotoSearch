• ย่อไฟล์ต้นฉบับได้ — เลือกรูปแล้วกด “ย่อไฟล์ต้นฉบับ” เพื่อคืนพื้นที่ดิสก์ ไฟล์ที่ย่ออยู่แทนในโฟลเดอร์เดิมชื่อเดิม ต้นฉบับขนาดเต็มย้ายไปถังขยะ (กู้คืนได้จนกว่าจะล้างถังขยะ)
• ใบหน้า ชื่อบุคคล และวันที่ถ่ายอยู่ครบหลังย่อ ไม่ต้องวิเคราะห์ใบหน้าใหม่
• ส่งออกสำเนาแบบย่อขนาดได้ — ด้านยาว 2048 / 1600 / 1080 px หรือกำหนดขนาดไฟล์ไม่เกิน สำเนาเก็บวันที่ถ่าย ข้อมูลกล้อง และโปรไฟล์สีไว้
• รุ่นนี้ปรับโครงสร้างคลัง แอปสำรองคลังเดิมไว้ให้ก่อนเมื่อเปิดครั้งแรก หลังจากนั้นแอปรุ่นก่อนหน้าจะเปิดคลังนี้ไม่ได้
