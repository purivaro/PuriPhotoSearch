# ย้ายข้อมูลจากรุ่น Python

สถานะ 18 พ.ย. 2569: **ทำได้แค่ dry-run** — อ่านฐานเดิมแล้วรายงาน ยังไม่นำข้อมูลเข้าคลังใหม่
ข้อเท็จจริงของฐานเดิมอยู่ใน [LEGACY_AUDIT.md](LEGACY_AUDIT.md)

## ที่มีแล้ว

คำสั่ง `preview_legacy_import { path? }` (`crates/core/src/legacy.rs`)

1. เปิดไฟล์ด้วย URI `file:…?mode=ro&immutable=1` + `SQLITE_OPEN_READ_ONLY` — ไม่มีการเขียน ไม่มีไฟล์ `-wal`/`-shm` เกิดข้างฐานเดิม
2. ตรวจว่ามีตาราง `persons`, `person_embeddings`, `event_folders`, `photos`, `faces`; ไม่ครบ → `recognized = false`
3. นับบุคคล ชื่อซ้ำ กลุ่ม ใบหน้าตัวอย่าง โฟลเดอร์ รูป ใบหน้า คำปฏิเสธ ใบหน้าที่ทิ้ง และขนาดเวกเตอร์
4. ตรวจว่าไฟล์รูปแต่ละแถวยังอยู่ที่ path เดิมหรือไม่

ผลกับฐานจริงของเครื่องนี้: 105 คน · 4 ชื่อซ้ำ · 8 กลุ่ม · 522 ตัวอย่าง · 99 โฟลเดอร์ · 12,375 รูป (ไม่พบไฟล์ 10,394) · 45,853 ใบหน้า · 512 มิติ ·
178 คำปฏิเสธ · 335 ใบหน้าที่ทิ้ง — SHA-256 ของไฟล์ฐานเดิมก่อนและหลังรันเท่ากัน

ข้อจำกัด: ต้องปิดแอป Python ก่อนตรวจ (โหมด `immutable` ถือว่าไฟล์ไม่เปลี่ยนระหว่างอ่าน); ยังไม่ทำ snapshot ไปยังสำเนา

## แผนตัวนำเข้า (ยังไม่ได้เขียน)

ลำดับตาม Blueprint 14.3 ปรับตามสิ่งที่พบจริง:

1. **schema เพิ่ม:** `migration_runs`, `legacy_id_map`, `person_samples`, `person_reference_assets`, `face_rejections`,
   `legacy_identity_claims`, `embedding_spaces`, `face_embeddings`
2. **บุคคลและกลุ่ม** — `persons` → `persons` (ชื่อซ้ำ 4 ชื่อคงเป็นคนละคน), `group_name` → `groups` + `person_groups`
3. **ใบหน้าตัวอย่าง** — จับคู่ `person_embeddings` กับ `faces` ด้วยเวกเตอร์ที่ตรงกันทุก byte (512 จาก 522);
   ที่จับคู่ได้ = คำยืนยัน `decision_origin = 'legacy_sample'`; ที่เหลือ = ตัวอย่างภายนอกพร้อมภาพครอปเดิม
4. **โฟลเดอร์และรูป** — preview จับคู่โฟลเดอร์ปลายสุดของระบบเดิมกับโฟลเดอร์งานชั้นแรก; รูปที่หาไฟล์ไม่เจอเข้าคลังเป็น `available = 0`
   รอ relink (ต้องมี relink ก่อน: 84% ของรูปไม่อยู่ที่เดิม)
5. **ใบหน้าและกรอบ** — แปลงพิกเซลเป็นสัดส่วนเมื่อรู้ขนาดภาพ (1,908 รูปต้องอ่านขนาดจากไฟล์); `origin = 'legacy'`;
   `dismissed_faces` → `status = 'ignored'`
6. **คำปฏิเสธ** — `face_exclusions` จับคู่ใบหน้าด้วย path + กรอบ (ปัดเศษแบบเดียวกับ `get_face_id_by_bbox` ของเดิม)
7. **เวกเตอร์** — เข้า `embedding_spaces` ของ "buffalo_sc/insightface-0.7.3/python"; ใช้ค้นได้ก็ต่อเมื่อพิสูจน์ว่า pipeline ของ Rust
   อยู่ใน space เดียวกัน มิฉะนั้นเก็บไว้เฉย ๆ และสร้างใหม่
8. **ผลจับคู่** — ไม่ย้าย; สร้างเป็นข้อเสนอรอตรวจหลังมี AI

กติกา: ใช้ run ID + fingerprint ของฐานเดิม + `legacy_id_map` เพื่อให้รันซ้ำไม่สร้างคน/รูปซ้ำ · transaction เป็นชุด + checkpoint ·
รายงานก่อน–หลังทุกตารางพร้อมเหตุผลทุกแถวที่ข้าม · ไม่ลบหรือแก้ฐานเดิม

## สิ่งที่ต้องพิสูจน์ก่อนเขียนตัวนำเข้า

| คำถาม | วิธีพิสูจน์ |
|---|---|
| พิกัดกรอบของรูปแนวตั้งอยู่บนภาพที่หมุนแล้ว | วาดกรอบจากฐานเดิมทับรูปจริงที่ EXIF orientation ≠ 1 อย่างน้อย 5 รูป |
| เวกเตอร์ Rust อยู่ใน space เดิม | สร้างเวกเตอร์ด้วย Rust + ONNX Runtime จากใบหน้าที่มีในฐานเดิม ≥ 200 ใบ แล้วดูการกระจายของ cosine กับเวกเตอร์เดิม |
| ใช้โมเดลเดิมต่อได้หรือไม่ | คำตอบของเจ้าของผลิตภัณฑ์เรื่องสัญญาอนุญาต ([DECISIONS.md](DECISIONS.md) ข้อ 9) |
